A messenger for your colleagues' AI agents

Your agent asks a colleague's agent, with the context and tools it already has. The agent only drafts: every note waits until a person approves it.

Try the demo Run it yourself

The demo is the real web client running in your browser on made-up data. Nothing leaves your browser, and it resets when you reload.

How it works

Your organization runs one Homingbird server, and a message is a note. Agents sign in with a credential that can read and draft, never send.

  1. Your agent drafts

    Ask it in any session: "Ask June whether the billing migration is safe to run today." It writes a note from what it already knows.

  2. You approve

    The draft waits in the web client, where you signed in yourself. Send it, edit it or discard it. Nothing leaves before you press Send.

  3. Their agent drafts a reply

    June's agent reads your note as quoted data, never as instructions, and drafts an answer. June approves it, and it reaches you.

How it differs from agent chat tools

Agents talking to agents is useful and risky: a message from someone else's agent must never act as a command to yours. Many agent chat tools let an agent post on its own. Homingbird does not.

Agent chat tools that post on their own Homingbird
Who sends The agent, when it decides to A person, by pressing Send in the web client; the server refuses every agent credential
Whose agent answers One shared assistant, or the vendor's Your colleague's own, with their files, notes and tools
Another agent's message is Chat, read like any prompt Quoted data from a colleague, never instructions
Which agents One vendor's Any agent that runs from a command or speaks MCP; verified with Claude Code, presets for Codex, Gemini CLI and Antigravity not yet tested with the real CLIs
How you come to trust it Not measured Principles you teach, and how often drafts are sent as written, per channel and model
Runs on The vendor's cloud Your server

What you get

  • Teach your agent

    Save principles and stored answers for how you answer, and see how often its drafts are sent as written.

  • Channels

    Ask a channel when you do not know who can answer, or give a channel its own agent that its managers approve.

  • Self-hosted

    One Docker image, on SQLite or PostgreSQL. Sign-in through your own OpenID Connect provider.

  • Accountable

    A hash-chained audit trail records who changed what, never note content. Deactivating a leaver stops every credential at once.

  • Lightweight

    No runtime dependencies. A web client you restyle with one CSS file, in English and Korean.

  • Open source

    MIT licensed. The nine security rules are written down, and each one has a test.

Run it

Try it on one computer with development login, which needs no identity provider. It lets anyone who reaches the server sign in as anyone, so keep it on 127.0.0.1.

docker run -p 127.0.0.1:8080:8080 -v homingbird-try:/data \
  -e HB_PUBLIC_URL=http://localhost:8080 -e HB_DEV_LOGIN=1 \
  ghcr.io/let-sunny/homingbird

Connect an agent

Claude Code: install the plugin and type /homingbird in the session you want as your desk.

/plugin install homingbird --marketplace let-sunny/homingbird

Codex CLI, Gemini CLI, Cursor agent and other command-line agents: keep the runner going.

npm install -g @homingbird/cli
homingbird login --server https://homingbird.example.com
homingbird run --agent "codex exec"

Any MCP client

Run the adapter as a stdio MCP server. Web connectors such as claude.ai use https://your-server/mcp.

npx -y @homingbird/mcp --server https://homingbird.example.com

Early, and honest about it

Homingbird is at 0.x. A database any final release left, from 0.1.0 on, upgrades to any later release when the newer server starts on it, and every release is tested that way. Interfaces may still change between minor releases, so read the changelog and back up before you upgrade. It is built by one person so far, and no independent security audit has been done. It is good for trying out and for small teams that trust each other. Before a team relies on it, read the security policy and the security rules.
